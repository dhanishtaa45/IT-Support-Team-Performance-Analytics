# IT Support System Analytics – Project Documentation

## Project Objective
The objective of this project is to analyze IT support ticket data to evaluate team performance, SLA compliance, and customer satisfaction.

## Dataset Information
The dataset contains IT support ticket details including ticket ID, priority, issue type, agent information, resolution time, and customer survey results.

## Data Cleaning Steps
- Removed duplicate records
- Handled missing values
- Standardized column formats
- Converted date columns into proper date format
- Corrected inconsistent category values

## Data Analysis
Power BI was used to analyze the dataset and generate insights about ticket resolution, SLA compliance, and agent performance.

## Key Insights
- Ticket distribution by priority
- SLA compliance status
- Average resolution time
- Customer satisfaction ratings
- Agent performance comparison

## Tools Used
- Microsoft Excel
- Power BI
